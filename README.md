# 🔐 CyberBot – Cybersecurity Assistant

A beginner-friendly cybersecurity chatbot built using Python and Streamlit.

## Features
- Answers basic cybersecurity questions
- Provides information about phishing
- Explains password safety
- Introduces malware and cybersecurity
- Simple interactive chat interface

## Technologies Used
- Python
- Streamlit
- GitHub

## Run Locally

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`

## Purpose
This project was created as a beginner cybersecurity learning project to explore Python, chatbot logic, and web application deployment.

## Disclaimer
CyberBot provides basic cybersecurity awareness information for educational purposes.
